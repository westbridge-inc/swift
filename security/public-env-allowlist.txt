# Public environment variables — the allowlist [GRD-1 §2, WS-15 / 15.8]
#
# THE LAW THIS FILE ENFORCES: anything shipped inside an app binary or a web
# bundle is PUBLIC. Not "hard to find" — public. Obfuscation, code splitting and
# certificate pinning change nothing; a determined reader has the bytes. So a
# build-time-inlined value is a value you have published.
#
# `EXPO_PUBLIC_*` (Metro) and `NEXT_PUBLIC_*` (Next.js) are both INLINED AT
# BUILD TIME. Giving a secret one of those prefixes does not expose it later, by
# some mistake — it publishes it, immediately, in every install. This file is
# the complete set of names allowed to carry those prefixes, each with a written
# reason. `scripts/public-secrets-gate.js` fails the build on any name that is
# not here, and CI runs it on every PR.
#
# FORMAT — one entry per line:
#     NAME [!not-a-secret] # justification
#
# The `!not-a-secret` marker is REQUIRED for, and only for, a name whose text
# matches the secret-word pattern (KEY, SECRET, TOKEN, PASSWORD, CREDENTIAL,
# DSN, PRIVATE, AUTH). Three legitimate names do (NEXT_PUBLIC_ALLOW_SITE_TOKENS,
# EXPO_PUBLIC_SENTRY_DSN and NEXT_PUBLIC_MAPTILER_KEY), and the marker makes each a deliberate, reviewed act
# instead of a silent exception.
#
# ADDING AN ENTRY IS A SECURITY DECISION. Before adding one, answer in the
# justification: what is the value, who can read it once it ships, and what can
# they do with it? If the answer involves "they shouldn't be able to", the value
# does not belong in a bundle — it belongs behind a server-side proxy.

EXPO_PUBLIC_API_URL # The API base URL the mobile app calls. A public hostname; every request from every install already announces it. Not a credential — the API authorizes per request.
EXPO_PUBLIC_WEB_URL # The public website origin, used to build the courier tracking link a sender shares with a recipient (#799). It is a URL customers are meant to receive.
NEXT_PUBLIC_API_URL # Same public API hostname, for the web and admin apps. The admin build separately REFUSES a plaintext http:// URL on a non-local host.
NEXT_PUBLIC_ALLOW_SITE_TOKENS !not-a-secret # A build ESCAPE HATCH, not a credential: set to '1' it lets apps/web compile while site.config.ts still holds its three {{TOKEN}} placeholders. It carries no value of its own and grants nothing at runtime. CI sets it so the site builds before the founder fills the real legal details; deploy-web.yml deliberately OMITS it, so on the real deploy the refusal IS the gate. It matches the secret-word pattern only because the placeholders it permits are called "tokens".
VITE_API_URL # The API base URL the Mission Control desktop app calls — the same public hostname the mobile and web apps announce. The packaged app separately REFUSES a plaintext http:// value (apps/desktop/src/lib/api.ts).
VITE_RESTORE_SESSION # A developer opt-in flag for the desktop preview: set to restore a saved session without the packaged app's prompt. A boolean switch with no value of its own; it grants nothing at runtime.
EXPO_PUBLIC_LINK_PREVIEW_HOSTS # [MOB-002] Comma-separated PREVIEW/staging hostnames a preview build may accept as Swift deep-link origins, on top of the production web origin. Public hostnames by definition; empty in production builds. It can only ADD exact hosts to the link policy for that build and grants nothing at runtime.
EXPO_PUBLIC_SENTRY_DSN !not-a-secret # [L13 item 7] The mobile crash-report address (a Sentry-protocol client DSN) for Swift's self-hosted error tracker. Client DSNs are designed to ship inside apps: possession lets an install SUBMIT a crash report and nothing else (no read access, no project settings). Unset means crash reporting is OFF. It matches the secret-word pattern only because the protocol calls the address a DSN. Set by the owner as an EAS environment variable, never committed.
NEXT_PUBLIC_CARD_FRAME # [CARD embed] '1' when this web build may show the bank's card page inside the weekly-fee page (an iframe of Swift's own API card page); absent otherwise. Set only by next.config from the build switch SWIFT_WEB_CARD_FRAME, together with the CSP frame-src for the API origin. A boolean with no value of its own: anyone can read it, and it grants nothing; the server still decides whether card payments are live.
NEXT_PUBLIC_MAPTILER_KEY !not-a-secret # [WEB-TILES, owner ruling 14 Oct #5] The website's MapTiler BROWSER key for its map tiles (apps/web/src/lib/map-tiles.ts). Who can read it: anyone who opens a page with a map, because every tile request carries it, as MapTiler designs browser keys. What they can do with it: request MapTiler map tiles; MapTiler serves them only to the origins the owner restricts the key to (the site's own names), it reads and changes nothing in Swift or in the MapTiler account, and a script that copies it and fakes the Referer can only spend the plan's tile quota, which MapTiler caps and the owner can rotate. Set by the owner at a hidden prompt as deploy/.env WEB_MAPTILER_KEY (a web build argument), never committed. Unset: the built site draws no map tiles. It matches the secret-word pattern only because MapTiler calls it a key.
